## 一、HTML 基础（20 知识点）

### 1. HTML 语义化 ❗❗❗

HTML  语义化是用更清晰，更好理解的标签替代原本的 `div` 标签，HTML语义化的好处有：
对机器:
	更好的识别网页内容，有利于爬虫，有益于SEO。还支持读屏软件，生成目录。
对人类：
	更好的阅读网页的源代码，清晰的了解页面的结构设计。

### 2. 常见语义化标签 ❗❗❗

- `header` 头部 
- `nav` 导航
- `section` 页面的内容块
- `main` 页面主要内容
- `article` 独立完整可分发的内容单元
- `aside` 侧边栏
- `footer` 页面尾部内容

### 3. 块级元素、行内元素、行内块元素 ❗❗❗

块级元素是独占一行的元素，通常有自己的高度宽度，可以包含块级和行内元素。
行内元素一般是文本类，没有固定的高度宽度，可以共存一行，可以包含行内元素，除了`a`标签，可以包含块级元素。
行内块元素是最特殊的，它们既有行内元素的特点又有块级元素的特点，如`button`可以有高度宽度又能共存在一行。

### 4. 替换元素与非替换元素 ❗❗

替换元素是一个会因为属性变化而改变内容的元素，如`img`和`video`等。
非替换元素是不会随属性改变的元素。
### 5. 表单元素与表单提交 ❗❗❗

表单最重要的元素就是`form`，是所有表单元素的父元素，决定了表单提交的数据提交到哪(`action`)，用什么方式(`method`)，数据是什么类型(`enctype`)。表单提交使用submit进行提交。
表单内元素有input和label组成。

### 6. input 常见类型 ❗❗❗

input的常见类型有
- `text` 文本
- `password` 密码
- `email` 邮箱
- `number` 数字
- `tel` 手机号
- `url` 网址
- `search` 搜索
- `date` 日期选择器
- `time` 时间选择器
- `datatime-local` 日期+时间
- `color` 颜色选择器
- `range` 范围滑块
- `file` 文件上传
- `checkbox` 多选框
- `radio` 单选
- `button` 按钮
- `submit` 提交按钮
- `reset` 重置按钮
### 7. label 标签的作用 ❗❗❗

- 语义关联：label 标签的作用是用 for 和 id 绑定表单控件
- 提升可访问性：点击 label 也能触发控件
### 8. button 默认 type ❗❗❗

默认为submit，会提交表单，除此之外还有`button`和`reset`type。
### 9. HTML5 新特性 ❗❗

带来了语义化标签，多媒体标签（`video`,`audio`），`Canvas`画布，本地存储(`localStorage`, `sessionStorage`,`cookies`), 离线缓存`Service Workder`，实时通信`WebSocket`，还有新的表单type，还有`Web Workders`JS多线程，还有Drag and Drop拖拽。

1. 语义化标签，增加代码可读性，让页面结构变得更加清晰。
2. 多媒体标签，支持了视频和文本内容的展示。
3. 图形，提供了绘图API和相关的`Canvas`组件。
4. 本地存储，增加的相关的API可以将数据存储到本地。
5. 离线缓存，使用Service Worker可以让网页离线访问。
6. 实时通信，支持WebSocket双向通信。
7. 表单增强，增加了email、data等输入类型。
### 10. video 与 audio ❗❗

Viedo和Audio是HTML 5加入的新组件，用于展示视频和音频内容，可以使用Img类似的用法。
### 11. canvas 基础 ❗❗

Canvas 是HTML 5 添加的画布标签，可以使用JS创建绘图。
### 12. meta viewport ❗❗❗

可以设置桌面端网页在移动端的页面内容缩放。
### 13. SEO 基础 ❗❗❗

SEO全称为 Search Engine Optimization 搜索引擎优化。可以让搜索引擎更好的收录你的网页，提升搜索排名。

主要方式有：
1. 使用 meta 标签进行优化，填写页面标题内容介绍和关键词还有作者等信息。
2. 还有结构化数据，对标签添加`itemprop`结构化组织页面内容。
3. 使用语义化标签可以更好的组织项目。
4. 使用链接优化避免无意义的链接跳转。
5. 使用完整的图片`alt`和`title`有助于图片的SEO
