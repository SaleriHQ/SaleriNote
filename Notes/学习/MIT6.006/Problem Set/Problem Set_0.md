## 题目 0-1 [√]

设 $A=\{i^2+i \mid i \in \mathbb{Z} \text{ 且 } 0 \le i \le 4\}$，且 $B=\{3i \mid i \in \{1, 2, 4, 5\}\}$。
计算：  
(a) $A \cap B$  
(b) $|A \cup B|$  
(c) $|A - B|$  

## 题目 0-2

设 $X$ 为表示抛掷三次均匀硬币后正面朝上次数的随机变量。设 $Y$ 为表示投掷两枚均匀六面骰子并将它们的点数相乘结果的随机变量。请计算以下期望值。
计算：  
(a) $E[X]$  
(b) $E[Y]$  
(c) $E[X+Y]$  

## 题目 0-3

设 $A=600/6$ 且 $B=60 \bmod 42$。以下命题是真还是假？
评估：  
(a) $A \equiv B \pmod 2$  
(b) $A \equiv B \pmod 3$  
(c) $A \equiv B \pmod 4$
