# 堕化该隐（里该隐）全机制与运营教学：从入门到独眼高手

堕化该隐（Tainted Cain，社区常称**里该隐**）是《以撒的结合：忏悔》中玩法最独特的角色。他无法像常规角色那样直接拾取道具，而是通过次要主动**合成宝袋**（Bag of Crafting）收集基础掉落物进行合成。

本篇教程结合了**以撒Wiki官方数据**与**Bilibili UP主 Zekyu 等8位里该隐高手的视频教学精华**，从底层机制、固定配方、掉落物价值、房间运营、道具推荐到实战黑科技，为你系统拆解这位“独眼高手”的通关密码。

---

## 一、 角色基础与解锁条件

*   **解锁方式**：使用任意角色携带“红钥匙”（Red Key）或“红钥匙碎片”（Cracked Key），前往 **Home** 层的走廊，在妈妈房间门外的走廊左侧墙壁使用，打开隐藏红区卧室，触碰其中的堕化该隐。
*   **初始属性**：与常规该隐完全一致（1.2移速、3.5伤害、1.0射速倍率等），初始携带一把钥匙。
*   **专属道具**：次要主动【合成宝袋】。

---

## 二、 核心机制详解

### 1. 道具拆解机制
当里该隐试图接触房间内的普通道具底座（Pedestal Item）时，道具不会被直接拾取，而是会**原地爆开**，拆解为若干基础掉落物（心、硬币、钥匙、炸弹等）。
*   *例外*：在极个别特定情况下（如剧情道具）可以直接获得道具。

### 2. 合成宝袋（Q键）操作指南
*   **挥动宝袋**：按下 `Q` 键举起宝袋，按射击方向挥动。可对敌人造成 3 点固定接触伤害、阻挡敌方弹幕、打开普通宝箱。
*   **收集掉落物**：用宝袋挥击地上的掉落物，即可将其装入袋中。
    *   *商店交易*：如果挥击商店出售的商品，若角色硬币足够，会自动扣除硬币并将物品直接装入袋中。
*   **袋内操作**：
    *   **查看预览**：袋子里装满 8 个掉落物后，屏幕右下角 UI 将显示合成出的预览道具。
    *   **移动/调整材料**：点击切换键（默认 `Ctrl` 键），可以循环移动袋中掉落物的位置。
    *   **溢出替换**：对预览道具不满意时，继续收集新的掉落物会将其加入袋中，并**替换掉左上角（最旧）**的掉落物。
    *   **完成合成**：长按使用主动键（或长按 `Q` 键）1 秒，会清空袋内掉落物并生成对应的预览道具。

## 四、 掉落物价值与合成品质算法

合成道具的品质由袋中 8 个掉落物的**总价值**决定。掉落物的数量决定合成次数，掉落物的价值决定道具品质，掉落物的特殊属性决定道具池。

### 1. 掉落物合成价值表
根据官方 Wiki 及底层机制，不同掉落物在袋中贡献的质量分数如下：

| 价值分数 | 对应掉落物 |
| :---: | :--- |
| **1分** | 铜币（Penny）、半红心、红心、腐心（Rotten Heart） |
| **2分** | 钥匙、炸弹、双铜币、微型电池（Micro Battery）、普通胶囊、红钥匙碎片（Cracked Key） |
| **3分** | 镍币（Nickel，5分硬币）、粘性镍币 |
| **4分** | 魂心（Soul Heart）、符文/魂石、骰子碎片（Dice Shard）、普通电池（Lil' Battery） |
| **5分** | 黑心（Black Heart）、永恒之心（Eternal Heart，白心）、骨心（Bone Heart）、十美分（Dime）、金心（Gold Heart） |
| **7分** | 金钥匙、金炸弹、金胶囊、黄金电池（Golden Battery）、金币 |
| **8分** | 幸运币（Lucky Penny）、大电池（Mega Battery） |
| **10分** | 巨型炸弹（Giga Bomb） |

### 2. 合成品质区间
袋中 8 个消耗品的分数相加，其总分决定了产出道具的品质区间：

| 掉落物总分 | 产出道具品质（Quality）区间 |
| :---: | :--- |
| **40分 以上** | **品质 4**（神性、圣心、硫磺火等） |
| **32 ~ 39分** | **品质 3 ~ 4** |
| **28 ~ 31分** | **品质 2 ~ 4** |
| **24 ~ 27分** | **品质 2 ~ 3** |
| **20 ~ 23分** | **品质 1 ~ 2** |
| **14 ~ 19分** | **品质 0 ~ 2** |
| **0 ~ 13分** | **品质 0 ~ 1** |

> [!TIP]
> **运营避坑**：总分在 19 ~ 26 分区间时，极易合出尴尬的 2 级低性价比道具。建议在前期合成时尽量遵循“低配低，高配高”原则，将总价值控制在 **19 分以下**（合成廉价过渡道具）或 **26 分以上**（冲刺高品质大件），避免资源浪费。

## 五、 特殊房间与道具池控制

正常情况下，合成宝袋只会生成**宝箱房、Boss房、商店**道具池的道具。若想合成其他特殊房间（如天使、恶魔、隐藏）的道具，必须依靠在**对应房间拆解道具**产生的“独特掉落物”来引导道具池：

*   **天使房**：拆解底座道具必定生成 **永恒之心（白心）**。袋子里包含白心会大幅提升合成出**天使房道具**的概率（每个白心约 +10% 权重）。
*   **恶魔房**：拆解底座道具必定生成 **黑心**。袋中包含黑心会提升合成**恶魔房道具**的概率。
*   **隐藏房**：拆解底座道具必定生成 **骨心**。袋中包含骨心会提升合成**隐藏房道具**（如岩石底座 Rock Bottom、死亡证书 Death Certificate 等）的概率。
*   **诅咒房**：拆解底座道具必定生成 **腐心**。可用于定向合成**诅咒房/猫套（Guppy）**系列道具。
*   **星象房**：拆解底座道具必定生成 **符文**。
*   **红区隐藏房（超隐/红区）**：拆解底座道具必定生成 **红钥匙碎片（Cracked Key）**。

## 六、 关卡运营与路线抉择

里该隐的通关核心在于**将低价值资源升值，并定向获取高价值资源**。

### 1. 天使房 vs 恶魔房
推荐走**天使房**路线：
*   **优势**：天使房拆解道具无需消耗血上限；击杀天使雕像获得的钥匙碎片（Key Piece）可以再次拆解，稳定提供包括白心在内的高价值资源。
*   **恶魔房劣势**：里该隐初始血量仅 2 红心，进行恶魔交易会极大压缩血上限上限；同时恶魔房交易机制改变后无法像以前一样利用力量卡等白嫖，容易导致资源链断裂。

### 2. 商店升值法
里该隐逛商店的目标是“资源升值”：
*   使用硬币（价值 1）购买商店里的魂心或电池（价值 4）装袋，能直接提升袋内质量。
*   商店里打折的商品、10 块钱的特价主动道具也是极佳的拆解资源来源。

### 3. 献祭房（极其重要）
献祭房是里该隐滚雪球的发动机：
*   献祭第 10 次概率产出的 **7 个魂心**（价值 28 分）和第 11 次产出的 **30 个硬币**（价值 30 分）能够极其轻松地转化成一次甚至数次高品质合成。

### 4. 赌博房与超级隐藏房
*   **赌博房**：提供献血机和恶魔乞丐。利用多余红心卖血可产出大量硬币、镍币，甚至直接刷出主动道具拆解。
*   **超级隐藏房（超隐布局）**：部分超隐房间拥有固定的特殊心（黑心/白心/骨心）布局，配合特殊手段（如罐子、大理石等）可以原地起飞。

## 七、 强力道具与饰品推荐

### 1. 优秀道具
*   **蛇蝎之吻（Serpent's Kiss） / 黑暗乞丐（Dark Bum）**：通过接触击杀或转化红心，能源源不断提供黑心（价值 5）作为高品质合成底料。
*   **伪造药学博士证（False PHD）**：将负面胶囊转化为黑心，同时提供攻击力。
*   **药学博士证（PHD）**：识别胶囊，并且能让献血机掉落更多硬币。
*   **迈达斯之触（Midas' Touch）**：将敌人石化并掉落大量金币。
*   **主教冠（The Mitre）**：大幅提升清理房间掉落魂心的概率。
*   **天秤座（Libra）**：里该隐可以低成本合成大量移速、射程类道具，天秤座能将这些溢出属性平衡为极高的伤害与射速，产生质变。
*   **深口袋（Deep Pockets）**：在无清理奖励时补充硬币，为合成提供稳定低保。
*   **长子名分（Birthright）**：**里该隐的最强核心道具**。合成后，拆解道具生成的掉落物数量翻倍，彻底开启无限资源时代。

### 2. 关键饰品与黑科技
*   **黄油（Butter!）**：
    *   **用法**：使用主动道具时会将其丢弃在地上。里该隐在特殊房间（如天使房、隐藏房）丢弃主动道具后再次触碰，该道具会原地拆解。利用此机制可以在特殊房间无中生有地刷出白心、骨心等定向材料！
*   **商店积分（Store Credit） + 补货机（Restock）无限白嫖 Bug**：
    *   **原理**：持有【商店积分】饰品时，商店商品价格归零。如果里该隐**使用合成宝袋挥击**免费商品将其收入袋中，系统将**不会消耗**商店积分饰品。配合商店的补货机，可以达成零成本无限刷商店资源、拆解道具的循环。
*   **老旧电容（Old Capacitor）**：使掉落物中的电池出现率大幅增加。
*   **破损的口袋（Cracked Pocket）**：受伤时将多余的炸弹、钥匙、硬币喷出并转化为更有价值的物品。
*   **猴爪（Monkey Paw）**：残血时提供黑心，相当于赠送高分合成材料。
*   **领养文件 (Adoption Papers)**：改变商店的道具池为跟班/宝宝，并将它们折扣至10硬币，在缺乏高价值掉落物时可以作为过渡饰品选择。

## 八、 实战黑科技：便携式老虎机“洗牌”套路

这是里该隐最经典的破局套路，适用于任何局势：

1.  **合成目标**：**便携式老虎机（Portable Slot）**。
    *   **固定配方**：8 个硬币（8 Pennies）。
2.  **操作步骤**：
    *   收集 8 个最容易获得的硬币，合成便携式老虎机。
    *   在身上已经持有一个主动道具（哪怕是另一个老虎机）的情况下，再次收集 8 个硬币合成老虎机。
    *   合成成功的瞬间，身上原有的主动道具会被**原地拆解**为若干随机掉落物。
3.  **核心收益**：
    *   通过此方法，你相当于用 **8 个硬币（价值 8 分）** 兑换了一批全新的、随机的掉落物。
    *   拆解出来的掉落物有很大概率包含钥匙、炸弹、魂心、镍币等高价值资源（价值远超 8 分）。
    *   只要有足够的金币（可通过赌博房、深口袋或献血机轻松获取），就可以无限次“洗牌”，直到洗出黑心、白心、骨心等顶级材料，一步登天。
    *   *进阶配合*：如果你能在诅咒房利用腐心“凑猫套”（Guppy系列道具），由于猫套散件品质低且效果易叠加，用洗出的材料很容易能将猫套凑齐。

> [!WARNING]
> **圣球冲突**：如果你合成了**十字圣球（Sacred Orb）**，它会阻止游戏生成品质 0 ~ 1 的道具。这会导致便携式老虎机（品质 0）的固定配方失效，合成物将被强制变为**早餐（Breakfast）**。因此，若计划使用此套路，请**千万不要**提前合成十字圣球！
